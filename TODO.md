## Branch review 2026-10-22: lower-priority findings

The ten most severe findings of the adversarial `/code-review` of `fix/review-findings-2026-10-17` were reported separately; these are the rest.

- [ ] **Pinch-zoom over the canvas is gone on touch devices (decision).** `#canvas { touch-action: none }` (`app/src/style.css`) keeps drags from being cancelled as pans, but the app has no zoom of its own, so on a phone a large model's labels stay tiny. Options: allow `pinch-zoom` in `touch-action`, or add an in-app zoom. Leaning to in-app zoom and pan (d3-zoom: pinch on touch, wheel on desktop), built with the fit policy above (Amelia, 2026-10-26, asked how hard; answer: medium, one branch). Decided (Amelia, 2026-10-27): one finger on the empty canvas draws the selection box; panning is two fingers (and the wheel or a drag modifier on desktop, to settle when building).
- [ ] **A drag can be cancelled by an unrelated touch.** `onCancel` in `app/src/render/drag.ts` ends the session on any window `pointercancel` without checking the pointer id; a second finger scrolling the inspector cancels the first finger's node drag.
- [ ] **Read-only or disabled text fields count as drop targets.** `isTextEntry` (`app/src/ui/textEntry.ts`) ignores `readOnly`/`disabled`, so a link dropped on such a field is not intercepted and can navigate away. No such fields exist yet. Also `describeTarget` returns null for a Text-node target instead of using its parent element.
- [ ] **Drag decision partly in the DOM handler.** The `dropEffect` choice and the "intercept but do not load" branch live in `main.ts`, not in a tested pure function; one function returning `load | refuse | pass` would cover both. The dropzone also highlights for a link drag it will refuse.
- [x] **Command headers abbreviated to four letters are not recognised (fixed 2026-11-01 with the abbreviated keywords item).** `SECTION_HEADER_RE`, `MODEL_HEADER_RE` and `VARIABLE_HEADER_RE` in `app/src/parser/dgm.ts` accept four or more letters. Mplus itself writes the headers in full in the `.dgm` (seen in one run, 2026-11-01: `ANAL:` came back as `ANALYSIS:`), so this matters only for hand-edited files; option names stay as typed. The full-word list is confirmed complete by the Guide.
- [ ] **Row matching scans every edge for every row.** `matchEdgeForRow` (`app/src/model/graph.ts`) is O(rows x edges); a keyed map lookup would do. Not measurable at today's sizes.
